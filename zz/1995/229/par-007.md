| | | | | | 2208 | Etylalkohol nedenaturovaný s merným alkoholometrickým titrom menším ako 80 % vol.; destiláty, likéry a ostatné liehové nápoje; zložené alkoholické prípravky používané na výrobu nápojov | 240 Sk/l a.
