## Úrad komisára pre osoby so zdravotným postihnutím

# § 12

(1) Zriaďuje sa Úrad komisára pre osoby so zdravotným postihnutím so sídlom v Bratislave.

(2) Úrad komisára pre osoby so zdravotným postihnutím je právnická osoba, ktorá sa nezapisuje do obchodného registra.

(3) Štatutárnym orgánom Úradu komisára pre osoby so zdravotným postihnutím je komisár pre osoby so zdravotným postihnutím.

(4) Podrobnosti o organizácii, činnosti a úlohách Úradu komisára pre osoby so zdravotným postihnutím upravuje štatút, ktorý vydá komisár pre osoby so zdravotným postihnutím.
