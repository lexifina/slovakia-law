# § 5 Vzdelávacie inštitúcie ďalšieho vzdelávania

Vzdelávacie inštitúcie sú:

- a) gymnáziá, stredné odborné školy, konzervatóriá, školy pre deti a žiakov so špeciálnymi výchovno-vzdelávacími potrebami, základné umelecké školy, jazykové školy (ďalej len „školy“)<sup>8</sup>) a vysoké školy,<sup>4</sup>) ktoré okrem školského vzdelávania uskutočňujú aj vzdelávacie programy,

- b) právnické osoby,<sup>9</sup>) ktorých predmetom činnosti je vzdelávanie a činnosti priamo súvisiace so vzdelávaním,

- c) fyzické osoby–podnikatelia,<sup>10</sup>) ktorých predmetom činnosti je vzdelávanie a činnosti priamo súvisiace so vzdelávaním.
