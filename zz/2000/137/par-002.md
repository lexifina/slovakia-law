# § 2 Program rozvoja bývania

Programom rozvoja bývania je

- a) program sociálneho bývania, ktorým je

  - 1. program pre mladých občanov,

  - 2. program výstavby bytového domu, v ktorom sú byty určené na nájom<sup>1</sup>) (ďalej len „program nájomných bytov“),

  - 3. program pre občanov s ťažkým zdravotným postihnutím,<sup>2</sup>)

  - 4. program výstavby zariadení sociálnych služieb podľa osobitného predpisu,<sup>3</sup>)

- b) program podpory mobility pracovnej sily (ďalej len „program mobility“),

- c) program obnovy bytového domu (ďalej len „program obnovy“).
