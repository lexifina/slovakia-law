# § 2

(1) Výkazy predkladané bankou a obchodníkom s cennými papiermi na účely spoločného výkazníctva sú tieto:

- a) výkazy pre vykazovanie vlastných zdrojov a požiadaviek na vlastné zdroje a vykazovanie strát pochádzajúcich z úverov zabezpečených kolaterálom vo forme nehnuteľnosti podľa vzorov a metodiky na ich vypracúvanie uvedených v prílohách č. I, II, VI a VII osobitného predpisu,<sup>2</sup>) ktoré pozostávajú z týchto častí:

  - 1. Kapitálová primeranosť podľa kódov C 01.00, C 02.00, C 03.00 a C 04.00 ustanovených v osobitnom predpise,<sup>2</sup>)

  - 2. Prechodné ustanovenia podľa kódov C 05.01 a C 05.02 ustanovených v osobitnom predpise,<sup>2</sup>)

  - 3. Platobná schopnosť skupiny podľa kódov C 06.01 a C 06.02 ustanovených v osobitnom predpise,<sup>2</sup>)

  - 4. Kreditné riziko podľa kódov C 07.00, C 08.01, C 08.02, C 09.01, C 09.02, C 09.04, C 10.01, C 10.02, C 11.00, C 12.00, C 13.00 a C 14.00 ustanovených v osobitnom predpise,<sup>2</sup>)

  - 5. Operačné riziko podľa kódov C 16.00 a C 17.00 ustanovených v osobitnom predpise,<sup>2</sup>)

  - 6. Trhové riziko podľa kódov C 18.00, C 19.00, C 20.00, C 21.00, C 22.00, C 23.00,

  - C 24.00 a C 25.00 ustanovených v osobitnom predpise,<sup>2</sup>)

  - 7. Expozície a straty pochádzajúce z úverov zabezpečených kolaterálom vo forme nehnuteľného majetku podľa kódu C 15.00 ustanovených v osobitnom predpise,<sup>2</sup>)

- b) výkazy pre vykazovanie veľkej majetkovej angažovanosti a rizika koncentrácie podľa vzorov a metodiky na ich vypracúvanie uvedených v prílohách č. VIII a IX osobitného predpisu,2) ktoré pozostávajú z veľkej majetkovej angažovanosti podľa kódov C 26.00, C 27.00, C 28.00,

- C 29.00, C 30.00 a C 31.00 ustanovených v osobitnom predpise,<sup>2</sup>)

- c) výkazy pre vykazovanie finančnej páky podľa vzorov a metodiky na ich vypracúvanie uvedených v prílohách č. X a XI osobitného predpisu,<sup>2</sup>) ktoré pozostávajú z vykazovania finančnej páky podľa kódov C 47.00, C 40.00, C 41.00, C 42.00, C 43.00 a C 44.00 ustanovených v osobitnom predpise,<sup>2</sup>)

- d) výkazy pre vykazovanie likvidity podľa vzorov a metodiky na ich vypracúvanie uvedených v prílohách č. XII, XIII, XVIII, XIX, XX, XXI, XXIV a XXV osobitného predpisu,2) ktoré pozostávajú z týchto častí:

  - 1. Krytie likvidity podľa kódov C 51.00, C 52.00, C 53.00 a C 54.00 ustanovených

  - v osobitnom predpise,<sup>2</sup>)

  - 2. Stabilné financovanie podľa kódov C 60.00 a C 61.00 ustanovených v osobitnom predpise,<sup>2</sup>)

  - 3. Dodatočné ukazovatele na sledovanie likvidity podľa kódov C 67.00, C 68.00, C 69.00, C 70.00 a C 71.00 ustanovených v osobitnom predpise,<sup>2</sup>)

  - 4. Vykazovanie likvidity podľa kódov C 72.00, C 73.00, C 74.00, C 75.00 a C 76.00 ustanovených v osobitnom predpise.<sup>2</sup>)

(2) Výkazy podľa odseku 1 písm. a) tretieho bodu až siedmeho bodu sa nepredkladajú obchodníkom s cennými papiermi, ktorý spĺňa podmienky podľa osobitného predpisu.<sup>3</sup>)

(3) Výkazy podľa odseku 1 písm. a) tretieho bodu a piateho bodu sa nepredkladajú obchodníkom s cennými papiermi, ktorý nespĺňa podmienky podľa osobitného predpisu.<sup>4</sup>)

(4) Výkazy podľa odseku 1 písm. b) sa nepredkladajú obchodníkom s cennými papiermi, ktorý spĺňa podmienky podľa osobitného predpisu.<sup>5</sup>)

(5) Výkazy podľa odseku 1 písm. c) sa nepredkladajú obchodníkom s cennými papiermi, ktorý spĺňa podmienky podľa osobitného predpisu.<sup>6</sup>)

(6) Výkazy podľa odseku 1 písm. d) sa nepredkladajú obchodníkom s cennými papiermi, ak sa postupuje podľa osobitného predpisu.<sup>7</sup>)
